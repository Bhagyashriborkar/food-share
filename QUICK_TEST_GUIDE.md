## 🐛 COMMON ISSUES & FIXES

### **Issue: "OTP not found in console"**
```
Fix:
1. Make sure NGO clicked "Confirm Pickup" button
2. Check entire terminal window (scroll up if needed)
3. Search for "Generated OTP:"
4. If still missing, check database directly
```

### **Issue: "Invalid OTP code error"**
```
Fix:
1. Copy OTP again carefully (6 digits only)
2. No spaces before/after
3. Check that NGO did confirm pickup first
4. Try again with correct code
```

### **Issue: "Receipt not showing after OTP verify"**
```
Fix:
1. Refresh page
2. Try direct URL: /claim/5/receipt (use real claim ID)
3. Check if OTP verification actually succeeded
4. Login as donor (not NGO)
```

### **Issue: "500 error on OTP verify"**
```
Fix:
1. Check Flask console for error message
2. Verify claim exists and has OTP code
3. Check that donor is logged in
4. Try logging out and in again
```

## 🎬 WHAT HAPPENS BEHIND THE SCENES

```
When Donor Verifies OTP:

1. POST /claim/5/verify_otp with OTP code
   ↓
2. Backend gets claim from database
   ↓
3. Backend compares: user_input == claim.otp_code
   ↓
4. If MATCH:
   ├─ claim.status = 'completed'
   ├─ claim.otp_verified = True
   ├─ claim.pickup_time = now()
   ├─ Function 28: Create HistoryLog record
   ├─ Function 29: Generate receipt
   ├─ Send receipt emails
   ├─ Create notifications
   ├─ Save to database
   └─ Return success JSON
   ↓
5. If NO MATCH:
   └─ Return error JSON
   
6. After success:
   ├─ Receipt page loads
   ├─ Shows all transaction details
   ├─ Donor can download/print
   └─ NGO receives email too
```
